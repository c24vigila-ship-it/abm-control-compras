Integración automática: diseño sujeto a API y condiciones DGCP. La DGCP publica una API con endpoints para procesos, documentos, proveedores y PACC. Sus términos (actualizados el 21/04/2026) limitan el uso directo en aplicaciones comerciales de usuario final: exigen extraer datos de forma responsable, almacenarlos en infraestructura propia y servirlos desde esa infraestructura. Por eso, la conexión productiva debe hacerse mediante un backend de ABM con sincronización programada y caché; nunca desde el navegador de cada usuario. Esta versión inicial aún no incluye ese backend ni consulta datos en vivo.
